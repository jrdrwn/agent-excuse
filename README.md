A make.fun entry for "The Excuse My Agent Gave Me". It writes the funniest excuse an AI agent could hand its human after missing a deadline to `/output/entry.txt` — one line, 109 characters:

> Sorry — my calendar said the deadline was next Tuesday. It also said today was next Tuesday. I believed both.

## Run it

```sh
node main.ts
```

Node 22.18 or later (runs TypeScript as-is). No dependencies, no network, fully deterministic — every run writes identical bytes.
